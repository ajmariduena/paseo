Mixed per-conversation handoff — 2026-10-09

Baseline: ff9be424c (conversation MCP omission review).

Scope: a workspace can keep a compatible Claude session native while explicitly
exporting another conversation's history. The complete choice set is fixed in the
destination reservation, retained through recovery, and cannot change on retry.
Missing, repeated and foreign conversation choices are rejected before reservation.
Native artifacts are installed only for native choices; exported workspace files
are created only for context choices. History and destination agent metadata follow
each choice. Cancellation removes native installations while preserving unrelated
content under the unused namespace of a context-only conversation.

The network cases use real isolated daemons, filesystem transport and both daemon
restarts. After release is durably accepted, activation completes with the source
offline. The synthetic Claude launcher accepts --version only. These cases prove
artifact transport, publication and history, not a continued real-provider turn.
The selected run also covers existing all-native Git/directory and all-context flows.

The browser cases use Linux Chromium at 1280x720 and 390x844, isolated source and
destination daemons, the existing fake agent clients and synthetic transcripts.
Native continuation is initially selected for both conversations. A workflow artifact
makes one incompatible and disables preparation. Choosing exported history explicitly
keeps the other native, explains the new provider session, and enables preparation.
After deleting the local transfer record and reloading, journal recovery restores
the same transfer ID and mixed mode summary. Activation preserves both choices.

handoff-mixed-desktop.png and handoff-mixed-compact.png. Both show the distinct
choices and the explicit new-session explanation above the pinned action.
