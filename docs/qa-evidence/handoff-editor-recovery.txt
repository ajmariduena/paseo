Editor recovery before workspace handoff — 2026-10-09

Baseline: d98a004a4 (save-before-handoff). Changes in this commit are web editor
checkpoints, restoration, discard and persisted-copy handoff admission.

Coverage: Linux Chromium, real isolated daemons, real browser storage and file RPCs.
No provider turn. No main daemon restart. This is not the physical MacBook/VPS test.
Electron/macOS/Windows, native app surfaces and concurrent app windows are untested.
Recovery applies to completed local checkpoints. Clearing the browser profile or
crashing before a checkpoint completes can lose that recovery copy. Other clients'
buffers and conversation draft transfer remain delivery gates in the owning plan.

The model regression first reproduced an unresolved recovered conflict becoming
an autosave after the first ordinary observation. A second regression reproduced
loss of the local copy when editing back to original bytes during a disk conflict.

Performance probe: baseline model versus edit + completed recovery checkpoint.
Node on the same Linux host, 20 warm-up edits and 100 samples at each file size.
The persistence port serializes the actual draft to JSON, including its base.
This isolates model/serialization overhead; it does not include localStorage I/O,
CodeMirror rendering, browser responsiveness or device performance. There is no
claim of a browser frame-time budget from these numbers.

Reproduce the baseline module:
git show d98a004a4:packages/app/src/file-pane/editor/model.ts > /tmp/handoff-editor-baseline.ts
Run the following script with node --import tsx /tmp/handoff-editor-recovery-perf.mts.
import { performance } from 'node:perf_hooks';
import beforeModule from './handoff-editor-baseline.ts';
import afterModule from '/home/paseo/.paseo/worktrees/354ubo4e/juvenile-gorilla/packages/app/src/file-pane/editor/model.ts';
const { FileEditorModel: Before } = beforeModule;
const { FileEditorModel: After } = afterModule;
for (const bytes of [65536, 524288, 1048576]) {
  for (const [name, Model] of [['before', Before], ['after', After]] as const) {
    let checkpointBytes = 0;
    const model = new Model({
      file: {content: 'x'.repeat(bytes), hasBom: false, version: {status:'ready',cwd:'/workspace',path:'bench.txt',size:bytes,modifiedAt:'2026-10-09T00:00:00Z'}},
      session: {write: async () => {throw new Error('Not a file-save benchmark');}},
      clock: {setTimeout: () => 1 as never, clearTimeout: () => {}},
      persistDraft: async (draft) => { checkpointBytes = JSON.stringify(draft).length; },
    });
    const samples: number[] = [];
    for (let i = 0; i < 120; i++) {
      const started = performance.now();
      model.edit(`${'x'.repeat(bytes)}${i}`);
      if ('flushRecoveryDraft' in model) await model.flushRecoveryDraft();
      if (i >= 20) samples.push(performance.now() - started);
    }
    model.dispose();
    samples.sort((a,b) => a-b);
    console.log(JSON.stringify({name,bytes,samples:samples.length,medianMs:samples[50],p95Ms:samples[95],checkpointBytes}));
  }
}
